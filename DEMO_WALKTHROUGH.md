# Forge Permit: a bounded delegation demonstration

A parent agent delegates a report without giving its child broader permissions or a fresh tool budget.

1. Read the approved synthetic brief. Requests for a private file or traversal outside approved inputs are denied.
2. Attempt an oversized export and a broader child capability. Both are denied.
3. Delegate a narrower report-export task. The child exports report.txt within its one-file, 512-byte allowance and the remaining ancestor budget.
4. Inspect the exact output bytes, hashes and decision/outcome receipts.

See REPRODUCE.md for the supported macOS setup and commands. This is a scripted synthetic workflow, not a demonstration of an LLM choosing these actions. Unit tests separately exercise aggregate quotas and other controls. The successful workflow does not establish crash recovery or interruption qualification.

## What exists and what funding would add

The existing prototype uses a broker and macOS Seatbelt isolation after trusted bootstrap. Recorded tests are described in observed-evidence.json. These are bounded results, not production security certification.

The proposed funded work adds a qualified Linux backend, a plain Python integration, a pinned ROMA integration, explicit unresolved-operation presentation, independent security review and external reproduction. None of those future integrations is claimed as completed. No ROMA partnership or endorsement is implied.

Permissions and budgets refer to approved tool calls and file/export bytes, not model tokens or money. Existing private Forge software and data are outside this package.
